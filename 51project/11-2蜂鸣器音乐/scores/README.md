# 简谱参考与编谱数据

`qifengle-notes.txt` 由原工程的 `music1/新建 文本文档.txt` 原样复制，保留其作为编谱笔记的内容。[《起风了》参考简谱](../images/qifengle-reference.jpg)由项目整理者从网络资料提供，并说明可以公开使用；保留原图署名，不将其标记为本人原创曲目或原创谱面。

## 两类材料的区别

| 材料 | 名称与用途 |
|---|---|
| 参考图片 | 数字简谱：用数字、音区点、时值线等记录旋律和节奏 |
| TXT 笔记 | 音符—时值数据：如 `L7,1`、`M1,1`，用于整理程序播放数组 |
| `../mian.c` 中的 `Music[]` | 当前程序实际读取的数组，包含结束标记 `0xff` |

`L`、`M`、`H` 分别表示低、中、高音区，后接音级；下划线表示对应升音。每个音符后面的数值是时值单位，原程序采用 `delay(SPEED / 4 * 时值)` 控制音符持续时间。

## 笔记与当前代码的差异

两个版本都含 285 个事件，但第 189～192 个事件有差异：

| 事件序号（从 1 开始） | TXT 笔记 | 当前 `Music[]` |
|---|---|---|
| 189 | `M1,1` | `M6,1` |
| 190 | `M7,2` | `M7,5` |
| 191 | `M6,1` | `M1,1` |
| 192 | `M7,5` | `M7,2` |

以上记录只说明文件版本差异，并未判定哪一版与参考谱完全一致。本次未改动任何音谱数据；复现现有程序请以 `mian.c` 为准。

## 来源与使用说明

个人贡献为根据参考旋律整理音符与时值数据，不代表原创作曲、作词或制谱。参考图片保留原有署名；本项目未为第三方曲目或谱面额外声明 MIT、CC0 等许可证。若提供了原始发布页面，可继续补充具体来源链接。

参考图写有 `1 = #F`、4/4 拍及每分钟 77 拍。当前程序直接按已有频率表映射音符，且 `SPEED = 500`，不应宣称已精确还原参考图的原调与原速。
