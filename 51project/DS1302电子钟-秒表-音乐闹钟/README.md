# DS1302 电子钟、秒表与音乐闹钟

这是一个基于 51 单片机的原创综合应用项目，在普中 A2 开发板上完成实机验证。程序把 DS1302 实时时钟、矩阵键盘、8 位数码管、AT24C02 和蜂鸣器组合为多模式电子钟。

## 功能

- 显示时分秒与年月日，并支持按键设置。
- 显示秒表，支持启动/暂停、清零。
- 设置闹钟时间，并将闹钟参数写入 AT24C02。
- 到达闹钟时刻后，通过蜂鸣器播放预设旋律。

## 硬件接口

| 模块 | 单片机接口 | 说明 |
|---|---|---|
| 矩阵键盘 | P1.0–P1.7 | 模式切换、时间设置与秒表控制 |
| 8 位数码管 | P0、P2.2–P2.4 | P0 输出段码，P2 控制位选 |
| DS1302 | CE=P3.5、IO=P3.4、SCLK=P3.6 | 实时时钟与日历数据 |
| AT24C02 | SCL=P2.1、SDA=P2.0 | 保存闹钟参数；软件 I²C |
| 蜂鸣器 | P2.5 | Timer1 定时翻转输出音调 |

## 按键操作

按键扫描函数返回的键值用于控制应用：键值 1 进入或退出设置，键值 2 切换显示模式，键值 3 选择设置字段，键值 5/6 调整字段，键值 4 启停秒表，键值 8 在秒表模式清零；键值 7 保存闹钟参数。具体按键位置以普中 A2 开发板键盘布局为准。

## 工程与验证

- 使用 Keil µVision 的 C51 工具链，打开 `project.uvproj` 编译。
- Keil 工程目标为 AT89C52；当前工程配置中的时钟字段为 24 MHz。
- 作者已在普中 A2 开发板完成实机验证。此处记录的是作者的板上验证，不代表本次整理后由 Codex 重新编译或复测。
- AT24C02 驱动已放在本工程目录，工程不再依赖相邻秒表项目的源文件。

构建输出目录 `Objects/`、`Listings/` 和 Keil 本机界面配置不纳入版本控制。
